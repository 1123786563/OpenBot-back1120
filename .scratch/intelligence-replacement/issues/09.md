# T09: 手动学习形成可审核提案

## Parent

Part of #83 — https://github.com/1123786563/OpenBot/issues/83

## What to build

用户选择已完成对话或已提交录制，运行 Learn now 并查看有证据的 Insight 与 Learning Proposal。

## Acceptance criteria

- [ ] 通过产品界面手动选择材料并启动分析，显示排队、运行、成功、失败状态及归属。
- [ ] 完成对话、完整录制与明确提交的不完整片段可作为材料；未确认上传材料不得进入分析。
- [ ] 分析模型调用使用已验证的付款归属、预算与预留，未经授权不能收费。
- [ ] 生成新增、更新或移除 Skill 的提案，包含理由、证据、目标技能版本和待审核状态。
- [ ] 用户可查看、批准或拒绝自己的提案；拒绝或尚未批准不能改变 Bot 技能。此票批准可显示待发布，不假报已交付。
- [ ] 跨个人材料与提案被拒；模拟分析失败不产生假完成提案，重复启动按已定义契约去重。
- [ ] 提供用户可观察行为的测试或演示证据，遵守父规格及既有 ADR；不得把静态分析或模拟测试当作真实服务验收。

## Blocked by

- T04 — 辅助模型调用的授权与积分闭环：其交付是本票所用链路的前置条件。
- T08 — Recorder 完整上传与断点续传：其交付是本票所用链路的前置条件。

## Completion gate

仅当上述验收全部满足、阻塞票已完成且外部前置条件已验证时才可完成。遇到源码、账本或第三方能力缺口须明确报告阻塞，不静默降级要求。
