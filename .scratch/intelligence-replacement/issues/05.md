# T05: 个人 Memory 审核与本地召回

## Parent

Part of #83 — https://github.com/1123786563/OpenBot/issues/83

## What to build

用户管理 Memory，Bot 仅能使用已接受且获准的记忆，并可在本地基础检索。

## Acceptance criteria

- [ ] 界面与服务端支持原文、来源、版本、审核状态、编辑、接受、暂停与遗忘。
- [ ] 通过 Bot 形成与 Memory Source 导入两条入口生成待审记忆；用户接受前不进入模型上下文。
- [ ] 来源权限撤销与 Bot 可见范围由服务端执行；跨用户、跨 Bot 未授权记忆均不进入召回。
- [ ] 编辑、暂停和遗忘立即影响下一次读取，重复请求和并发编辑不恢复旧内容。
- [ ] 在 Hindsight 不参与的情况下，通过 Bot 对话演示获准记忆基础检索；不把基础检索标为高级推理。
- [ ] 用不同主体的唯一内容标记检查实际模型输入，不能只检查最终答案没有泄漏。
- [ ] 提供用户可观察行为的测试或演示证据，遵守父规格及既有 ADR；不得把静态分析或模拟测试当作真实服务验收。

## Blocked by

- T02 — 持久化一段 Conversation 并恢复历史：其交付是本票所用链路的前置条件。

## Completion gate

仅当上述验收全部满足、阻塞票已完成且外部前置条件已验证时才可完成。遇到源码、账本或第三方能力缺口须明确报告阻塞，不静默降级要求。
