# T07: Memory 故障同步、撤销与重建

## Parent

Part of #83 — https://github.com/1123786563/OpenBot/issues/83

## What to build

Hindsight 停机期间的记忆修改安全生效，恢复后补同步且可从权威记录重建。

## Acceptance criteria

- [ ] 停机时仍可编辑、接受、暂停和遗忘，普通对话用本地检索；显示同步状态而非假报完成。
- [ ] 恢复后按当前版本同步，迟到任务不能覆盖新编辑或恢复已遗忘内容。
- [ ] 安全数据同步可重试；含收费模型调用的同步先查处理状态，不盲目重复提交。
- [ ] 模拟同步和撤权并发，不让失效副本进入召回或推理；无法保证时明确降级。
- [ ] 清空测试副本后从 OpenBot 重建，保留原审核与可见范围，不导入待审或停用记忆。
- [ ] 用故障注入证明任务重复、重启及部分成功均不会重复扣费或复活旧版本；记录可验证证据。
- [ ] 提供用户可观察行为的测试或演示证据，遵守父规格及既有 ADR；不得把静态分析或模拟测试当作真实服务验收。

## Blocked by

- T06 — Hindsight 获准记忆检索与推理：其交付是本票所用链路的前置条件。

## Completion gate

仅当上述验收全部满足、阻塞票已完成且外部前置条件已验证时才可完成。遇到源码、账本或第三方能力缺口须明确报告阻塞，不静默降级要求。
