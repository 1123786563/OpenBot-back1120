# T08: Recorder 完整上传与断点续传

## Parent

Part of #83 — https://github.com/1123786563/OpenBot/issues/83

## What to build

用户主动录制并上传到 OpenBot，能够区分停止、上传完成和不完整片段。

## Acceptance criteria

- [ ] 实际录制端主动开始和停止，上传目标为 OpenBot；未开始时不采集示范。
- [ ] 服务端确认批次并按序号去重；断线、进程重启和重复提交后可恢复，不重复保存材料。
- [ ] 停止但尚未排空显示待上传，只有完整确认才标记可自动学习。
- [ ] 无法补齐时用户可明确提交已有片段，列表与材料详情持续标记不完整。
- [ ] 录制列表、内容访问和上传许可按个人归属检查，其他用户无法注入、读取或续传。
- [ ] 确定文件存储与录制契约，提供真实录制客户端到服务端的中断续传演示；不依赖 Intelligence gateway。
- [ ] 提供用户可观察行为的测试或演示证据，遵守父规格及既有 ADR；不得把静态分析或模拟测试当作真实服务验收。
