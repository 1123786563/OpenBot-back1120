## What to build

维护个人偏好、凭据、浏览器和计算机设置。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 盘点并迁移个人设置现有页面，其他票负责的 Skill/Memory 页面保持正确链接。
- [ ] 偏好保存与重新进入后状态一致；凭据保持遮蔽，不在日志或错误中暴露。
- [ ] 浏览器和计算机连接设置沿用原协议，成功/失败/断开状态正确。
- [ ] 现有敏感操作确认保留，取消不触发变更，权限不扩大。
- [ ] 验证保存、取消及失败恢复，检查键盘、窄屏和主题。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
