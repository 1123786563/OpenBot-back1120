## What to build

使用审计、主动工作、学习及诊断管理工具。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 覆盖审计、主动工作、学习、管理端 Skill、诊断/组件展示等现存管理入口。
- [ ] 列表过滤/分页及详情操作保持既有行为，空状态与加载失败正常。
- [ ] Learning Proposal 的待审核/批准/拒绝等现有流程不因 UI 迁移改变。
- [ ] 诊断/演练入口保留原有边界，不把预览结果当成已经执行的变更。
- [ ] 验证主要查询和变更路径、权限拒绝及主题/窄屏；不引入新的管理业务能力。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
