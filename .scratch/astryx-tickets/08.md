## What to build

通过现有入口浏览、创建、编辑 Skill 及查看 Bot 关联。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] Skill 列表、创建、详情编辑和 Bot 关联视图采用 Astryx，已存在的操作全部可达。
- [ ] 保存、校验、失败、空状态与未授权访问有正确反馈；刷新后内容保持一致。
- [ ] 保留共享/审核等现有权限与约束，Skill 声明的能力不自动成为 Bot Grant。
- [ ] 编辑器或专用内容组件保留实现，迁移外围控件；键盘与窄屏可操作。
- [ ] 验证查看、编辑成功、校验失败和权限拒绝行为。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
