## What to build

确认全部 Web 入口及跨页面流程已在统一界面中工作。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 建立当前路由与用户流程清单，包含旧别名、动态页面、全局错误页和未直接出现在导航的入口。
- [ ] 逐项记录已迁移归属、验证方式及结果；发现遗漏时补齐，不以主要页面截图代替全站覆盖。
- [ ] 验证登录→Bots→创建→Conversation→Approval/Computer，以及 Connection/Grant 等跨页面流程。
- [ ] 覆盖普通用户、管理员、个人版/团队版及能力差异，权限与入口一致。
- [ ] 统一检查明暗、品牌、窄屏、键盘及焦点，修复迁移造成的回归。
- [ ] 相关集成测试、Web 类型检查及生产构建通过，留存浏览器证据和明确未解决限制；有阻断缺陷不得进入清理。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
