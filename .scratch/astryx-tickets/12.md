## What to build

管理员维护人员、身份提供方、权限和边界。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 人员、身份提供方、权限描述/详情及边界创建/详情等现有管理入口覆盖完整。
- [ ] 查看、编辑、保存、删除等当前支持的行为保持，校验与错误反馈正确。
- [ ] 普通用户不可通过新 UI 执行管理员操作，服务端拒绝有明确反馈。
- [ ] 现有危险操作确认和策略含义保持不变，不新增认证或权限模型。
- [ ] 验证管理员允许路径与非管理员拒绝路径，检查表格/表单的键盘和窄屏。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
