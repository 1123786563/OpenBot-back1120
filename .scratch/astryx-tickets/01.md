## What to build

在现有 Bots 页面浏览和打开 Bot，并可回退至旧界面。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 接入 Astryx 预编译 CSS 与 neutral 主题，处理与现有 CSS 的层顺序，生产构建能加载正确样式。
- [ ] 复用现有查询和路由，Pinned、Yours、Shared with you、个人版 Included 分组正确，Bot 不重复出现。
- [ ] Hidden 默认折叠，展开及收起可用；加载、空列表、首次失败及后台刷新失败保持原有区别。
- [ ] Needs you、等待计数和对应跳转不丢失，Memory 等入口继续遵守部署能力。
- [ ] 明暗主题、品牌配置及窄屏正常；提供明确的试点启用和回退方法，验证旧列表仍可用。
- [ ] 复用列表集成测试覆盖分组、错误和跳转，完成浏览器截图、类型检查及构建；不得把已安装依赖当作完成。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。

## Blocked by

None (can start immediately).

仅在所有阻塞票完成后启动。第 3 票须获得用户明确视觉认可才算完成，后续票不得绕过该门槛。
