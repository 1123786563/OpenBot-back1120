## What to build

在对话中查看工具活动、代码、进度和委派结果。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 工具活动、代码卡片、进度和研究结果保持原有数据与展开/折叠交互。
- [ ] Task 和 Subagent 仍被正确区分，进入工作详情及返回原 Conversation 的路径可用。
- [ ] 运行中、完成、失败及中断的呈现与真实状态一致，不将 Run 完成误报为 Goal 达成。
- [ ] 保留代码/富文本等专用组件，长输出、增量更新与窄屏不丢内容。
- [ ] 验证代表性活动流、委派往返和结果继续交流，不用静态卡片演示替代行为检查。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
