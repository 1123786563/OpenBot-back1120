## Parent

Part of #40

## What to build

在独立页面和 Conversation 内使用计算机、浏览器和终端。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 独立 Computer/浏览器页面、Bot 关联视图及对话内入口覆盖，连接与断开状态正确。
- [ ] 保留现有画面、输入、尺寸适配和终端专用实现，只迁移外围控件。
- [ ] Browser Handoff 的接管和归还符合现有状态；人在持有控制权期间不出现误导性 Bot 操作入口。
- [ ] 权限、共享计算机及 Isolated Bot 边界保持，错误/重连反馈不掩盖真实状态。
- [ ] 用真实浏览器验证接管往返、终端输入和窄屏，记录所需后端环境及未通过项。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
