## What to build

从列表创建内置 Bot 或连接外部 Agent，成功后进入新 Bot。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 在现有创建状态和变更请求上更换基础组件，不复制创建业务逻辑。
- [ ] 名称、指令、默认值与校验保持不变；按钮禁用和处理中反馈正确，重复操作不重复创建。
- [ ] 外部 Agent 地址、密钥、框架选择及服务端连接检查保留；不可达和被拒绝时显示原因且不创建。
- [ ] 返回步骤或切换运行方式保留输入；应用选择与 Bot Grant 保持原有语义，不扩大授权。
- [ ] Public/Private、Isolated 选项遵守权限和部署能力，个人版文案及应用行为保持一致。
- [ ] 取消、Escape、点击面板外部及浏览器返回按原行为关闭；重开重置，成功导航后返回不重开空面板。
- [ ] 键盘可完成流程，焦点进入/约束/返回正确，中文输入法组合确认不会提交。
- [ ] 复用创建集成测试及 HTTP 测试响应，补齐迁移导致的行为差异；真实浏览器验证明暗、窄屏和弹层。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
