## What to build

通过统一框架访问现有功能，并切换主题。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 导航、页面框架和常用全局交互采用 Astryx；保留现有目的地与路由，不重组信息架构。
- [ ] 管理员、普通用户及不同部署能力看到正确入口，不能通过新控件绕过权限。
- [ ] 品牌名称/标识/颜色与明暗主题生效，窄屏导航可用，键盘及当前页状态清晰。
- [ ] 旧深链接和浏览器前进后退仍可用，未迁移页面可与新框架共存。
- [ ] 在真实路由环境验证入口与权限分支，浏览器检查主题和布局；保留旧皮肤代码直到最终清理。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
