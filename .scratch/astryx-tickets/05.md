## Parent

Part of #40

## What to build

完成登录、请求确认和首次使用后抵达原目标页面。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 登录、登录请求确认、onboarding 页面采用 Astryx，保留当前认证契约及回调参数。
- [ ] 成功、失败、过期、等待和重试状态有明确反馈，不泄露凭据或认证数据。
- [ ] 登录后的返回地址与首次初始化顺序不变，已登录用户不被错误送回初始化。
- [ ] 键盘、焦点、窄屏和明暗主题可用；验证成功及拒绝/过期路径。
- [ ] 只迁移现有 Web 流程，不在本票实现新的身份系统或修改其他客户端。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
