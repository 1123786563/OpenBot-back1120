## What to build

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 提供可复现启动和回退说明，列出测试环境、相关测试、类型检查与生产构建结果及已知限制。
- [ ] 提供 Bots 列表及创建流程的明暗主题、桌面和窄屏实际截图，含加载/错误等代表状态。
- [ ] 实际验证键盘、焦点、浏览器返回、内置创建及外部连接失败反馈。
- [ ] 核对品牌配置和未迁移页面未受全局样式破坏；未解决的功能回归必须修复后再提交验收。
- [ ] 在本 Issue 留存用户明确认可试点视觉效果的记录；技术检查通过或无回复不能代替认可。
- [ ] 未经用户明确认可不得关闭本票或开始后续全面迁移；若用户要求调整，修改并重新提供证据。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
