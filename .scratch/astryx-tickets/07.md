## What to build

浏览 App、建立 Connection、查看工具并管理 Bot Grant。

范围限于 Web UI，遵循父 spec 与 ADR 0001；保留业务/API/权限语义。每票包含实现和行为验证，不另拆测试票。

## Acceptance criteria

- [ ] 应用目录、连接创建/详情、工具详情及 Bot 授权关联页面采用统一组件。
- [ ] 连接成功、取消、失败、过期及重试按现有协议工作，不改变 OAuth 等外部流程。
- [ ] Connection、App、Bot Grant 保持独立概念；界面不会把连接成功误报为已授权 Bot。
- [ ] 授权新增/撤销及已有确认操作有效，权限和可授权能力边界不变。
- [ ] 验证连接和授权的成功/拒绝路径及刷新后状态；保留现有集成提供方，不在本票替换后端。
- [ ] 对本票改动运行相关行为测试、Web 类型检查及生产构建，记录实际结果；不以组件内部 DOM 或生成类名作为断言。
