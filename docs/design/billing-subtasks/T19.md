Blocked by: #66, #68, #71, #73, #75, #76, #77

## What to build

交付受控上线配置和故障/回滚方案，确保停止新交易时已有资金与消费仍可处理。

## 实施边界与当前状态

不重做各模块；将已验收模块组成可演练运维关卡。

## 阻塞关与解除条件

外部阻塞：正式套餐、资源单价、额度、Run上限及受控发布配置需明确。未确定时可演练测试配置但不能关闭正式关卡，不把访谈示例当售价。

只有上述前置任务验收完成后才进入本票正式实施；可以提前阅读和准备夹具，但不能用提前准备关闭本票。

## Acceptance criteria

- [ ] 记录正式价格、积分包、资源费率、基础/订阅额度和默认Run上限的版本与生效方式，历史订单/步骤保持原版本；缺配置不得销售。
- [ ] 演练数据库/账本故障拒绝新增消费而非误报余额不足；Lago断网可继续可靠本地记账并在恢复后收敛。
- [ ] 演练已收付款未发权益、退款未知、已发送调用未知用量、outbox积压的进程恢复和人工处置，不清库重跑。
- [ ] 回滚/停用开关停止新增购买和收费步骤，但保留通知、查单、退款、在途结算及对账处理，不退回供应商直连。
- [ ] 设置并验证未履约付款、冻结超过24小时、未知用量、同步与对账差异的可观察告警和处理责任，不泄露敏感内容。
- [ ] 执行隔离数据库备份恢复或等效恢复演练，恢复后幂等身份、流水、价格和待处理队列完整，防止重复发放/扣费。
- [ ] 报告配置与演练证据、仍未解除的商户/源码条件；本票不代替最终端到端上线决定。

## 测试边界与完成要求

遵循父规格 #61 与 ADR 0003/0004，保持 Lago 社区版、OpenBot 北京时间周期及唯一积分账本。优先从受信业务 API/用户行为验证，使用真实 PostgreSQL/Lago；支付协议票在外部适配器边界使用替身，真实商户结果由专门闭环票验证。参考模型或静态调研不能替代本票要求的生产模块/集成证据。

完成时附可重复命令或操作步骤、版本、期望/实际结果、故障场景和未验证范围；不得包含凭据。`ready-for-agent` 仅表示任务已说明清楚，不表示依赖或外部条件已解除。
