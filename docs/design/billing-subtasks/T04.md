Part of #61

Blocked by: #62

## What to build

提供可配置商品、精确定价和可复现周期计算，供订单与账本共同使用。

## 实施边界与当前状态

合同完成后可独立开发，无需后端源码或商户；本票不执行支付、发积分或调度实际任务。

## 阻塞关与解除条件

正式售价和额度属于上线配置关卡；本票用明确标记的测试商品即可验收，不可把测试数字发布为正式价格。

只有上述前置任务验收完成后才进入本票正式实施；可以提前阅读和准备夹具，但不能用提前准备关闭本票。

## Acceptance criteria

- [ ] 分别定义月付套餐、长期积分包、基础/订阅资源额度、资源单价和默认 Run 上限的版本化配置；缺正式配置时返回不可销售。
- [ ] 输入/输出/缓存 token、收费工具次数/时长按资源维度定价；每步汇总后按六位小数四舍五入成整数微积分，无浮点或流片段重复取整。
- [ ] 预留可固定价格版本，后续调价不改变旧步骤；历史消费可还原所用配置。
- [ ] 按原始生效日及北京时间生成半开周期，验证1月31日→闰年2月29日/普通年2月28日→3月31日、大小月、跨年及非零时分秒。
- [ ] 首次/过期重购从实际开通起算，提前续费接续、最多预购一期；下期积分只在下期开始到期触发，不在付款时提前可用。
- [ ] 定义下期换档、已预购先退后买及退款中禁止重复购买的可观察资格结果；不在本票创建退款状态机。
- [ ] 通过业务级报价及周期查询测试金额、时间、版本与负例；本地原型只作为样例，生产模块另有自动化验证。

## 测试边界与完成要求

遵循父规格 #61 与 ADR 0003/0004，保持 Lago 社区版、OpenBot 北京时间周期及唯一积分账本。优先从受信业务 API/用户行为验证，使用真实 PostgreSQL/Lago；支付协议票在外部适配器边界使用替身，真实商户结果由专门闭环票验证。参考模型或静态调研不能替代本票要求的生产模块/集成证据。

完成时附可重复命令或操作步骤、版本、期望/实际结果、故障场景和未验证范围；不得包含凭据。`ready-for-agent` 仅表示任务已说明清楚，不表示依赖或外部条件已解除。
