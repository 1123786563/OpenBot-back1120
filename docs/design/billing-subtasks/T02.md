Part of #61

Blocked by: 无任务前置

## What to build

确认微信和支付宝实际可用的支付产品、受支持浏览器和部署条件，交付可供联调使用的配置。

## 实施边界与当前状态

可立即核查；本票只负责商户环境与接入资格，不重复编写支付适配器。

## 阻塞关与解除条件

外部阻塞：商户授权访问、产品开通、受控密钥注入及公网 HTTPS 回调。缺少任一项保持未完成，并逐项记录负责人/解除条件；仅列配置清单不能关闭。

## Acceptance criteria

- [ ] 分别记录微信 mchid/绑定 appid 的 Native、H5 产品权限和支付宝应用电脑/手机网站支付权限的核实证据；只记录脱敏标识和配置名称。
- [ ] 验证安全密钥/证书存储及加载、回调域名和 HTTPS 可达性；私钥/APIv3 key 不进入仓库、票面、前端或日志。
- [ ] 固定官方 SDK/协议版本并记录验签、公钥或证书轮换方式；支付宝旧命名接口与 v3 REST 不混用未经核实路径。
- [ ] 形成电脑扫码、外部手机浏览器、微信内置浏览器、桌面客户端打开网页的能力矩阵；不支持环境明确外部浏览器引导，不暗中加入 JSAPI 范围。
- [ ] 确认通知、主动查询、退款及交易账单下载权限；区分沙箱/测试环境与真实商户产品，标明不能由沙箱证明的行为。
- [ ] 交付可被后续适配器加载的受控测试配置与回调联调入口；本票不主动收取真实用户款项，完整支付退款留给渠道闭环票。

## 测试边界与完成要求

遵循父规格 #61 与 ADR 0003/0004，保持 Lago 社区版、OpenBot 北京时间周期及唯一积分账本。优先从受信业务 API/用户行为验证，使用真实 PostgreSQL/Lago；支付协议票在外部适配器边界使用替身，真实商户结果由专门闭环票验证。参考模型或静态调研不能替代本票要求的生产模块/集成证据。

完成时附可重复命令或操作步骤、版本、期望/实际结果、故障场景和未验证范围；不得包含凭据。`ready-for-agent` 仅表示任务已说明清楚，不表示依赖或外部条件已解除。
