# 界面语言与内容语言分离

OpenBot 首批界面国际化支持简体中文（zh-CN）和英文（en）。翻译范围为产品提供的界面文案；用户输入、Bot 名称、对话内容、技能正文及外部服务原文保持原样，切换界面语言不改写这些内容。Bot 回复语言另行设计，避免界面偏好改变用户内容及 Bot 的工作指令。

首期覆盖 Web（`app/`）的完整操作流程，包括表单校验、错误提示及服务端生成的系统展示文案；其他客户端的独立界面后续处理。外部服务返回的错误原文保留。

账户支持“跟随浏览器／简体中文／English”，手动选择优先并跨设备同步。跟随浏览器时，中文浏览器使用简体中文，其余使用英文。日期、相对时间及数字格式跟随界面语言；时区、计费周期及币种规则保持原有含义。

可识别的系统标签随界面语言切换；已存为自由文本、无法可靠区分系统默认值与用户命名的历史内容保留原文，不批量翻译历史数据。新记录应能区分系统默认标题与用户命名。

OpenBot 自身错误使用稳定错误码，由界面提供翻译；未识别错误使用本地化通用提示，并保留可查看的原始详情。外部服务错误原文也放在详情中。

缺失翻译在运行时回退英文；开发及 CI 检查两种语言的键与插值参数完整性。验收要求范围内产品文案具备中英文翻译。产品术语遵循根目录 GLOSSARY.md，品牌名称保留。

未登录时根据浏览器选择界面语言，允许在本机保存手动选择，OpenBot 自身登录入口提供语言切换。登录后以账户设置为准，退出后恢复本机选择；独立身份服务托管的登录页面另行处理。

界面语言不改变现有语音识别及录制讲解的语言选择逻辑。Web 的验收范围包含交付时仍可访问的所有页面与界面变体，包括仍在使用的旧界面；实施时核实已退出的界面，避免翻译废弃代码。

切换语言立即更新当前界面，保留未提交表单、当前对话及进行中的操作，不刷新整个页面。账户偏好保存失败时保留本次显示语言，提示未同步到其他设备，并允许重试。

产品界面文案也包括占位文字、悬浮提示、无障碍标签、页面标题及 OpenBot 提供的通知文案。验收需分别验证中英文主要操作流程、语言偏好同步及退出恢复，并检查长英文、中文换行、插值与复数、日期及相对时间。服务端错误码调整须保持其他客户端可用，并运行相关构建与翻译完整性检查。
