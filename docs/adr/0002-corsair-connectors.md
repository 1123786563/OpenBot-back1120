# 使用 Corsair 替换现有连接器

选定 corsairdev/corsair 作为现有连接器的替换方向，首要目标是降低自研连接器的开发维护成本并扩大第三方应用集成覆盖；保留当前已使用的能力作为验收底线。

替换范围为 Composio / Arcade 集成代理，保留直接接入 MCP 的能力。采用 Corsair 开源自托管，接受自行运维及配置第三方 OAuth 应用，以掌握凭据和部署控制权。

Corsair 负责外部应用连接和调用；OpenBot 继续管理 Bot Grant、动作审批、Shared-use Approval 和审计。个人 Connection 仍属于个人，不因多人使用同一个 Bot 而共享。该边界延续 ADR-0001 中业务权限由 OpenBot 管理的决定。

切换时要求用户重新授权，不迁移旧代理保存的令牌；保留仍适用的应用配置和 Bot 授权关系。重新连接前，相关任务明确提示连接不可用。先用少量关键应用验证连接、调用、审批、审计和撤销的完整链路，再逐步切换其余已使用应用；其余应用达到同等能力后再移除旧代理。

个人 Connection 按组织和用户隔离，同一个人在不同组织分别建立连接；Shared Account 限定在所属组织，不跨组织自动复用。

首批验证应用为 GitHub 和 Slack。保留同一组织内同一个人在同一 App 连接多个账户并选择默认账户的能力。

按应用切换时，停止向旧代理提交新调用，等待在途调用结束后切换。已有待审批动作失效，必须重新确认才能执行；结果不明的写操作不自动重试。

首批同时验证 GitHub 和 Slack 事件触发 Goal，覆盖事件验签、组织与账户归属、重复事件去重，以及停用订阅后不再启动 Goal。

仅在新旧 Action 的行为、参数和权限范围确认等价时保留原 Bot Grant；新增或不等价的 Action 必须由管理员重新授权。

默认账户断开、授权撤销或令牌刷新失败时停止相关调用并提示处理，不自动改用其他个人账户或 Shared Account。已有任务绑定明确的 Connection，不随默认账户变更而改变执行身份。

OpenBot 持久化已接收事件，负责去重及启动 Goal 的重试；失败后支持人工重放，重放时重新检查当前订阅和权限。该保证不涵盖第三方未送达的事件，也不允许自动重做结果不明的写操作。

断开连接先立即禁止本地使用，再尝试远程撤销；远程撤销失败时保留待完成状态并重试，不将其报告为撤销成功。此决定调整现有提供方文档中先远程撤销再本地删除的流程。

完整替换实施前必须取得可修改的 OpenBot 后端源码。用户提供的 Corsair 源码位于 `/Users/wuyj/IdeaProjects/corsair`，用于核实依赖实现，不等同于 OpenBot 后端源码。

首批验收覆盖 GitHub 读取 Issue、创建 Issue、发表评论，以及 Issue 新建和收到评论时触发 Goal；Slack 读取获准频道消息、发送消息、回复线程，以及获准频道新消息触发 Goal。事件处理需防止 Bot 自己发出的消息反复触发自身。两者均验证个人多账户、默认账户、共享账户授权、审批、断开连接和跨组织隔离。

每个个人 Connection 和 Shared Account 分配独立的 Corsair 隔离标识，由 OpenBot 在服务端校验所属组织和使用权限。此标识不直接等同于 OpenBot 组织。

OpenBot 补充远程授权撤销流程：先禁用本地调用并使待审批动作失效，保留撤销所需凭据，远程撤销完成后再清理本地凭据。失败时保持待完成状态并重试。

OpenBot 后端源码位置仍待提供，不表示完整方案已获确认，不能将后端源码视为已取得。

本地依赖核查基线为 Corsair 提交 `a55063222eb1fdc04c12bf958fa03b2aadde8b24`（包版本 `0.1.190`）。账户查找与更新以 `(tenant_id, integration_id)` 为键，因此使用上述独立标识支持同应用多账户。当前 `disconnectConnection` 删除本地账户及关联实体、事件，不调用提供方撤销授权，也不清除审批队列，须由 OpenBot 按上述流程适配。

同一外部空间对应多个 Connection 时，OpenBot 按已登记的订阅和当前权限分发事件，并按订阅去重，不依赖 Corsair 的首个匹配账户自动路由，也不无条件跨组织广播。

上述自动撤销重试流程存在一个例外：远程授权由多个 Connection 共用时，先禁用当前连接并使其待审批动作失效，将远程撤销标记为“需要协调”，由有权管理员确认影响范围后处理，不自动重试远程撤销，也不报告撤销成功。

源码核查发现 Webhook 自动路由按 GitHub installation 或 Slack team 查找首个匹配账户，远程授权可能由多个连接共用，因此采用上述事件分发与撤销例外。以上为静态源码核查，尚未做运行验证。

GitHub 采用自建 GitHub App，由管理员安装到指定仓库并订阅事件；个人 Connection 使用用户授权身份操作，不以安装身份替代个人身份。先验证本地 Corsair 对安装、个人授权、调用和事件接入组合的兼容性，有缺口则补齐适配后再验收。
