# 解除 Intelligence 依赖，由 OpenBot 持有产品状态

为解除 CopilotKit Intelligence 依赖并保留现有产品能力，采用自托管 Hindsight 承接记忆存储、检索和基于记忆的推理，自托管 Opik 承接追踪、反馈和评估；OpenBot 持有对话、Run 与事件的权威记录，负责实时恢复、记忆审核与隔离、自动学习提案及技能发布、录制和文件生命周期。接受由 OpenBot 补齐相关服务与运维的成本，不以 Opik 追踪替代对话恢复或积分结算。

两项服务部署为云端 SaaS 内部服务。优先取得可修改的后端源码；若无法取得，须另行确认重建范围，不能将当前预构建镜像视为可直接完成替换的实现基础。

OpenBot 保存记忆权威记录，Hindsight 副本可重建；两个外部依赖故障不阻断普通对话，记忆降级为本地基础检索。运行恢复不自动重做结果不明的外部动作。自动学习默认先提案后批准，可由用户主动开启个人空间自动批准；Opik 默认仅记录元数据，正文限明确选择的评估与排障范围。不迁移旧 Intelligence 数据，也不删除旧数据。

技能按 Run 固定版本，发布冲突不能覆盖用户后续修改。业务材料默认持续保存，删除来源与保留独立学习成果分别处理；Opik 元数据和选中正文样本默认分别保留 30 天、7 天。最终验收须在 Intelligence 服务、凭据和许可证全部缺席的环境覆盖全部受支持客户端与故障场景。

整体方案已于 2026-11-17 获用户确认，本 ADR 状态为 accepted，与[设计记录](../design/intelligence-replacement.md)共同作为后续技术验证、实施和验收的正式依据。具体接入方式与实现前验证项仍需验证，尚未实现或运行验证。沿用现有身份、业务授权、连接器、模型出口与积分账本决策。
