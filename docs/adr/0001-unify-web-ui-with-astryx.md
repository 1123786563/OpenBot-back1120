# Web 前端逐步统一为 Astryx

OpenBot Web 目前维护四套皮肤及多种基础 UI 组件。为提高视觉一致性并减少自制基础组件维护，决定以 Meta Astryx 为统一设计体系，完成迁移后退出四套皮肤，而非长期新增第五套皮肤；保留明暗主题、品牌配置及现有业务功能、入口和流程。本次范围为 `app/`，其他客户端独立界面另行处理。

先迁移 Bots 列表和创建流程，保留旧界面以便回退；通过功能、视觉、可访问性及构建检查，并由用户认可试点视觉效果后，才分批推进全面迁移。专用交互能力保留原实现，基础组件优先采用 Astryx；旧依赖只在调用迁移完毕后清理。这接受了过渡期间两套基础组件共存的成本，以控制复杂交互回归风险，避免为技术栈纯度重写业务能力。
