# Bifrost 统一模型出口，OpenBot 保留调用授权与积分账本

为统一模型接入、供应商切换和平台密钥管理，采用独立部署的自托管 Bifrost 开源版，作为 OpenBot 管理的 API 密钥模型调用出口；现有订阅登录路径暂不迁移。OpenBot 保留会话、任务、工具执行、模型可用性和积分账本职责，每次调用经服务端校验并预留积分后才可转发，网关预算不替代账本。

管理员维护模型清单，用户在通过 Harness 兼容性验证的清单中选择。Run 固定供应商和模型；辅助调用可单独配置，但继承付款归属和原始消费上限。网关凭据按租户隔离，供应商密钥集中保管，网关默认不记录请求及响应正文。

首期明确关闭自动故障切换及 SDK、网关自动重试，网关不可用时停止新请求，不绕过直连。接受网关成为调用可用性的依赖，以保持统一校验、费用归属和模型行为可追溯；用户明确重试形成独立预留与结算。

详细已确认规则及技术待验证项见[设计记录](../design/bifrost-model-gateway.md)，积分规则沿用[计费设计](../design/billing.md)。当前缺少可修改、验证的完整后端账本实现；必须先通过测试积分的端到端验证，才逐步开放付费流量。整体设计已获用户确认；具体校验实现、账本接口、Bifrost 版本与首批兼容组合保留为技术验证项，不代表接入已实现或已验证。
